# PR-AI Assistant — Local AI Assistant

> Open-source AI assistant that runs language models entirely on your own Windows PC. Your conversations, documents and images never leave the machine.

## What is PR-AI Assistant?

PR-AI Assistant runs open language models on your own computer, with no account, no
subscription and no cloud. It was built for digital forensics work, where evidence must
not leave the examiner's machine, and it is just as useful as a private everyday
assistant.

It ships **without models**. You pick the ones you want from a built-in catalog, and the
application reads your PC (graphics card of any brand, RAM, processor) and tells you
which version of each model will run well on it.

## Key Features

- **Chat with local models.** Any GGUF model from HuggingFace. Runs on the graphics card
  (NVIDIA, AMD or Intel) or on the processor if there is none.
- **Recommends for your PC.** The catalog marks the quantization that fits your hardware,
  and the *Automatic* profile sets context size, GPU layers and threads for each model.
- **Investigation Mode.** For evidence analysis: examiner identification, chain-of-custody
  logging with UTC timestamps and SHA-256 hashes, evidence files loaded as context, and
  session export to TXT, HTML or JSON. Every answer carries a notice that it was
  generated by AI and must be verified by the examiner.
- **PR Academy.** An isolated mode for technical and legal questions, with no access to
  evidence.
- **Image generation** (optional) with Z-Image Turbo, entirely local.
- **Web search** (optional) through a [SearXNG](https://docs.searxng.org/) instance you
  run yourself. The button only appears once you have configured one.
- **Bilingual UI** — Spanish and English, auto-detected from the system language and
  switchable from the start screen.
- **Fully portable** — unzip and run: no installer, no registry, no admin rights.

## Installation

PR-AI Assistant is distributed as a zip with the application and its engines. There is
nothing to install.

1. Download one of the two packages from the
   [Releases page](https://github.com/PatagoniaRobot/PR-AI-Assistant/releases/latest):

   | Package | Size | For |
   |---|---|---|
   | `PR-AI-Assistant-1.0.0.zip` | 85 MB | **Any PC.** Uses the graphics card of any brand (Vulkan), or the processor. If unsure, take this one. |
   | `PR-AI-Assistant-1.0.0-NVIDIA.zip` | 604 MB | NVIDIA cards. Adds the CUDA engine, somewhat faster at reading long texts. |

2. **Verify what you downloaded** against the `.sha256` published next to it — see below.
3. Unzip it anywhere and open `PR-AI-Assistant.exe`. .NET is included.
4. On first launch, the app guides you to the catalog: search for a model, pick the
   recommended version (marked with a star) and download it.
5. Choose a mode, press **Start** and wait for the indicator to turn green.

The first answer with the Vulkan engine can take a few extra seconds while it prepares
the graphics card; it happens once.

### Verifying the download

Every release publishes a `.sha256` alongside each package.

```
certutil -hashfile PR-AI-Assistant-1.0.0.zip SHA256
```

Compare the result with the contents of `PR-AI-Assistant-1.0.0.zip.sha256`, or on a
machine with GNU coreutils: `sha256sum -c PR-AI-Assistant-1.0.0.zip.sha256`.

### A note on the SmartScreen warning

The executable is **not signed with an Authenticode certificate**, so Windows will show
a *"Windows protected your PC"* screen with *"Unknown publisher"* the first time you run
it. You need to click *More info → Run anyway*. Verifying the SHA-256 above is what
actually tells you the file is the one that was published.

## Privacy

All inference is local. The application only uses the network when you ask it to: to
search or download models from HuggingFace, to search the web through your own SearXNG
instance, and to download the image models. There is no telemetry.

In Investigation Mode every session is logged to
`%APPDATA%\PRImager\AIAssistant\Logs\` for the chain of custody.

## Known Limitations

- **AMD and Intel graphics cards are untested.** The Vulkan engine that serves them was
  tested on NVIDIA, where it works. If you have one, a report is very welcome.
- On AMD and Intel the free video memory is not measured, so the image memory indicator
  shows "unknown" (it does not prevent generating).
- **The image engine is not included in the packages.** To generate images, download
  `sd-server.exe` from [stable-diffusion.cpp](https://github.com/leejet/stable-diffusion.cpp/releases)
  `master-975-95b3090` and unzip it into `Tools\sd\bin\` (CUDA) or `Tools\sd\bin-vulkan\`.
- Some HuggingFace repositories require accepting a license and a read token before
  downloading. The application tells you when that happens.

## Building from Source

PR-AI Assistant is built with .NET 10 and WPF.

```bat
git clone https://github.com/PatagoniaRobot/PR-AI-Assistant.git
cd PR-AI-Assistant
dotnet build -c Debug
publish.bat
```

`publish.bat` leaves the application in `Publish\` and both packages, with their
`.sha256`, in `Paquetes\`. `publish.bat forense` builds the forensic edition into
`Publish-Forense\`: it is compiled without web search, model downloads or image
generation, so that code is not in its binary at all, rather than switched off.

The engines are not in the repository, because of their size. Before building, copy into
`src\PR-AI-Assistant\Tools\` the `llama-server.exe` and its `.dll` files from
[llama.cpp](https://github.com/ggml-org/llama.cpp/releases) release `b8671`: the CUDA
build in `Tools\` and the Vulkan build in `Tools\vulkan\`. Leave out `ggml-rpc.dll` and
`rpc-server.exe`.

Release details are in [docs/DISTRIBUCION.md](docs/DISTRIBUCION.md), and the test
benches, which run against the real application, in [Tests/README.md](Tests/README.md)
(both in Spanish).
